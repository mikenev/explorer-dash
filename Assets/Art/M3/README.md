# M3 art (jungle temple)
- `Models/*.fbx` – generated by `ArtSource/build_assets.py` (`blender -b -P ArtSource/build_assets.py -- <out>`), copied here.
- `Editor/ArtM3Setup.cs` – **Explorer Dash > Art M3 > Rebuild Art Prefabs** (batch: `-executeMethod ArtM3Setup.BatchRebuild`):
  importer settings, URP palette materials (`Materials/`), Animator controllers (`Animators/`), prefabs (`Resources/ArtM3/`), validation.
- `Scripts/ArtM3Skin.cs` – runtime hook (`RuntimeInitializeOnLoadMethod`) that dresses the generated scene's player, boulder
  and track tiles with the prefabs; no M1 script/scene edits. `ArtM3Skin.Load("Alligator")` etc. for obstacle code.

Units/axes: 1 unit = 1 m, models face +Z. Track pieces start at z=0 and run to z=20 (TrackManager.tileLength), path 8.5 m wide
(3 lanes x 2.5 m + 1 m). Walls are placed at x = +/-4.65. Pit is one lane wide (2.5 x 3 m) with origin at lane centre/ground.

Animator parameters
- Explorer: bools `Playing`, `Grounded`, `Sliding`; triggers `Stumble`, `Caught`. States Idle, Run, Jump, Slide, Stumble, Caught.
- Alligator: trigger `Lunge` (Idle -> Lunge -> Idle). Faces +Z; rotate 180 deg to face the runner. Lunge moves the body ~1 m forward.
- Vine: looping `Sway`; 4.6 m tall, anchor bar at the top.
