# Explorer Dash

A Unity 3D endless runner (original IP). A jungle explorer grabs a golden idol and flees a giant rolling boulder.

**Milestone 1 – playable core (gray-box art).**

## Open in Unity
- Unity **6000.3.26f1**, URP 17.3, Input System 1.20 (active input handling = Input System).
- Open the repo folder in Unity Hub. Scene: `Assets/Scenes/Main.unity`.
- The scene and URP/material assets are generated by `Assets/Editor/BuildWeb.cs` (menu **Explorer Dash > Rebuild Main Scene**).

## Controls
| Action | Keyboard | Touch / mouse |
|---|---|---|
| Change lane | Left/Right arrows, A/D | Swipe left/right |
| Jump | Up arrow, W, Space | Swipe up |
| Slide / duck | Down arrow, S | Swipe down |
| Start / restart | Space, Enter, R | Click / tap |

## Gameplay (M1)
- Auto-run forward in 3 lanes; speed ramps from 10 to 22 m/s.
- Smooth over-the-shoulder follow camera.
- Pooled track tiles spawn ahead and recycle behind the player.
- The boulder rolls behind you. Each stumble (hitting a root, or steering into the jungle wall) cuts the gap by 5 m; the gap slowly recovers. Gap 0 = crushed, game over, restart.
- Distance score + local high score (PlayerPrefs `ExplorerDash.HighScore`).

## Obstacle hooks (for M2)
- `IObstacle` – `OnPlayerHit(PlayerController)`; the player's trigger collider calls it.
- `ObstacleBase` – abstract MonoBehaviour, default = `player.Stumble()`; `CanAvoidByJump/CanAvoidBySlide` flags.
- `ObstacleSpawner.Populate(TrackTile tile, int tileIndex)` – called every time a tile is placed ahead. Spawn under `tile.obstacleRoot` at `tile.spawnPoints` (3 lanes × rows every 5 m). Children are cleared on recycle.
- `StumbleRoot` – the M1 placeholder obstacle (toggle with `ObstacleSpawner.spawnPlaceholderRoots`).
- `PlayerController.Stumble()` / `OnStumble` event; `Boulder.stumblePenalty`.

## Rebuild WebGL
```
Unity -batchmode -nographics -projectPath . -buildTarget WebGL \
  -executeMethod BuildWeb.Build -logFile build.log
```
(No `-quit`; the method exits the editor itself.) Output goes to `docs/` (gzip + decompression fallback, no threads), so GitHub Pages can serve it from `/docs` later. **Pages is not enabled yet.** Local test: `cd docs && python3 -m http.server`.
